# CREDITOHANA Website

Sitio web estático y responsive, listo para abrir en Visual Studio Code.

## Cómo verlo
1. Abre esta carpeta en VS Code.
2. Instala la extensión **Live Server**.
3. Haz clic derecho en `index.html` y selecciona **Open with Live Server**.

También puedes abrir `index.html` directamente en el navegador.

## Archivos principales
- `index.html`: estructura y contenido.
- `styles.css`: diseño, paleta y responsive.
- `script.js`: menú móvil, animaciones, formulario de WhatsApp y logos.
- `assets/images`: fotografías y logos proporcionados.
- `assets/banks`: placas SVG de referencia de instituciones financieras.

## Importante sobre logos bancarios
Los SVG dentro de `assets/banks` son placas de referencia para desarrollo y no reproducciones oficiales. Antes de publicar, reemplázalos por archivos oficiales y verifica las reglas de uso de marca de cada institución.
